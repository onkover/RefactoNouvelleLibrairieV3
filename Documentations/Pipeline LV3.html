Pipeline de rendu, classé par fréquence d'exécution

Chaque bande horizontale est un niveau de fréquence : ce qui y est placé s'exécute une fois par frame, par vue, par instance visible, par sommet, par face, par triangle ou par pixel. Le chantier 2 a créé la bande « sommet », qui n'existait pas : la transformation vivait dans la bande « face ». Clique un étage pour son détail. Cardinalités : scène ceinture, 4 vues, Référence F.

Ce que le chantier 2 a déplacé

La règle qui organise tout le pipeline

Règle de fréquence : un calcul s'exécute au niveau le moins fréquent où son résultat est encore constant. Le descendre d'un niveau multiplie son coût par le rapport des cardinalités.

Invariant de durée de vie

Le contenu du ClipSpaceBuffer n'est valide que pendant l'itération de l'instance qui l'a rempli. L'instance suivante l'écrase.

// ❌ Contre-exemple : conserver un pointeur au-delà de l'instance
const Vec4f* saved = clipBuf.Data() + vi;   // instance A
// ... instance B : TransformPositions réécrit le tampon
Use(*saved);                                 // lit un sommet de B, sans crash

Tout futur étage différé (tri de transparence, tuiles, file de triangles) devra copier ses sommets, jamais les référencer. En multithread, un tampon par thread.
