Compteur de couverture

Un triangle traverse trois zones : la boîte que RasterizeTriangle parcourt aujourd'hui, la plus petite boîte qui contient des centres de pixels, et les pixels réellement couverts. L'écart entre les trois mesure le travail perdu.

boîte actuelle : floor(min) … ceil(max)+1 boîte serrée : ceil(min−½) … floor(max−½) pixel couvert (règle top-left)

Une population de triangles

20 000 triangles tirés au hasard, sommets à ±1.0 px d'un point, soit des astéroïdes vus de loin. C'est une prédiction : le compteur branché dans le moteur dira laquelle de ces tailles ressemble à la ceinture.

–ρ = PixelsTested / tri
–τ = PixelsTight / PixelsTested
–f₀ = TrisCov0 / tri
–boîte serrée vide / tri

Règle de décision, fixée avant la mesure

1. τ ≤ 0,5  et  ρ ≥ 6   →  chantier 3a : resserrer la boîte (exact, 2 lignes)
                             les boîtes serrées vides sortent alors en O(1)
2. sinon, f₀ ≥ 0,4       →  chantier 3b : rejet précoce avant DrawTriangle
3. sinon                 →  chantier 2b : division par w + ToRaster par sommet

Dans tous les cas : gain vérifié en ABBA sur P-core (M8, M9), contre la Référence F.
