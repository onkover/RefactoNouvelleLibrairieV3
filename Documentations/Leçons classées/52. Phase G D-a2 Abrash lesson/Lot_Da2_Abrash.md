*Lot D-a2 — hiérarchie de tuiles 8 × 8 au-dessus des blocs Giesen (10/11) — LIVRÉ, À APPLIQUER ET MESURER (CONDITIONNEL)*

**Base** : LIB `e7cae94` / EXE `5203980` (D-a1c commité ; D-a1d présent dans le dépôt : nombre magique dans Viewport.h, `Test_Da1d_Snap`, mesure non reportée dans le plan). Commutateur de mesure **`LV3_RASTER_TILES`** (config.h §14) = T* en px ; 0 = sans hiérarchie ; défaut proposé 16 ; `#error` si 1 ≤ T* ≤ 7 ; en-tête CSV `tiles=`.

- **Objectif fonctionnel** : dessiner les grands triangles en visitant moins de blocs, image identique au bit (couleurs, Z, compteurs communs) ; plus rapide sur les grands triangles (murs, sols, lames), pas plus lent ailleurs. Conditionnel : si la mesure ne montre pas de gain, défaut 0.
- **Règle de déclenchement du plan (25/10) non remplie, assumé (D0)** : Covered/Tight rooms = 38 % (< 50 %, tenu) mais arêtes = 24 % du Render à la dernière ablation (D-a1, 03/11) et ≈ 14 % du noyau au banc (< 40 %). Lot fait quand même, en conditionnel : demande d'Onky, socle de D2 (binning) et d'un Hi-Z par tuile, gain mesuré côté fragments sur les tuiles pleines.
- **Méthode** : M. Abrash, *Rasterization on Larrabee*, Dr. Dobb's, mai 2009. Par arête, E' affine sur une tuile ⇒ extrêmes à deux coins : coin de rejet (max) = c + max(0,7A') + max(0,7B'), coin d'acceptation (min) = c + min(0,7A') + min(0,7B'). LV3 : couvert ⇔ E' ≥ 0 (intérieur positif, coins échangés par rapport au texte d'Abrash). **Test exact** (pas seulement conservatif) : les coins sont des centres de la tuile.
- **Conception (décisions)** :
  - D1 : chemin Giesen AVX2, voies 32 bits, boîte rognée ≥ T* dans les deux axes (`IsTiledTri<kTilePx>`), après l'aiguillage D-a1c (petits d'abord).
  - D2 : tuiles 8 × 8, **grille partant du coin (x0, y0) de la boîte** (pas alignée écran : contre-exemple 2) ; une tuile partielle = 8 blocs Fx32.
  - D3 : deux niveaux : 8 tuiles voisines (64 × 8 px) jugées par registre (voie j = coin de la tuile j ; 2 masques de 8 bits rej/acc par 2 OU + 2 movemask) ; puis blocs. Pas de niveau 64 × 64 (gain borné < 1 %).
  - D4 : tuile pleine → `BlockFull` / `ShaderSolid::Shade8Full` : `loadu` du Z (plus de maskload), même prédicat `_CMP_NLE_UQ`, écritures masquées par le seul test Z. Variante blend + storeu : pas de gain, rejetée.
  - D5 : `TilesFitInt32` : E' dans int32 sur [x0, x1+7] × [y0, y1+7] (2 coins par arête), sinon repli `RasterizeBlocks8Fx`. Voies de tuiles hors boîte modulaires, écartées par `inBox`.
  - D6 : `RasterizeTiles8Fx<Shader>` hors ligne (LV3_NOINLINE) ; `RasterizeBlocks8Fx` inchangé.
  - D7 : `NextRow()` sur les puits (ShaderSink, ShaderSink8 avec dStride/cStride lus une fois ; FrameBuffer::PitchBytes) : BeginRow une fois par tuile.
  - D8 : coin de la tuile j par `vpermd` depuis le registre des coins (au lieu de imul + diffusion).
  - D9 : pendant scalaire `ForEachCoveredPixelFxTiled` (LV3_SIMD = 0, TNR kScalarOnly).
  - D10 : compteurs RASTER_STATS `TrisTiled`, `Tiles8Rejected`, `Tiles8Full`, `Tiles8Partial`, `BlocksFull8` ; LaneBlocks8 = blocs **testés**. Filets Debug : « tuile pleine hors de la boite », « voie couverte hors de la boite ».
